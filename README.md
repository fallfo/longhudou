# 龙虎斗 · 兽棋版（网页版：同屏双人 + 联机对战）

上世纪八九十年代流行于中国大陆的「洋画片」纸牌游戏 **龙虎斗** 的网页复刻。
一整张画片 16 张牌（龙 8 张、虎 8 张），玩法就是**斗兽棋（兽棋）的翻牌版**：牌背面乱排，先手翻牌定阵营，然后轮流「翻牌 / 走一格 / 吃子」，吃光对方 8 张牌者胜。

- **单文件、零依赖、离线可玩**：全部内容都在 `index.html` 里（含样式、规则引擎、联机协议、16 张插画），不加载任何外部资源。
- **两种对战方式**：同屏双人（一台设备轮流）／**联机对战**（各人自己手机，输房间号进房，第三个人可以观战）。
- **手机优先**：竖屏自适应，点选操作，适合发到 QQ 群/微信群里用链接直接开玩。

## 一、怎么玩

| 级别 | 龙方 | 虎方 |
|---|---|---|
| 最大 | 龙王(1) | 虎王(9) |
| 2 | 神龙(2) | 东北虎(10) |
| 3 | 金龙(3) | 大头虎(11) |
| 4 | 青龙(4) | 下山虎(12) |
| 5 | 赤龙(5) | 绿虎(13) |
| 6 | 白龙(6) | 妖虎(14) |
| 7 | 风雨龙(7) | 白虎(15) |
| 最小 | 变形龙(8) | 小王虎(16) |

1. **开局**：16 张牌背面朝上乱排在桌上（默认摆成 4×4 一整版，最贴近原画片）。
2. **定阵营**：先手翻开任意一张，**翻到哪一方就用哪一方**，另一方用剩下的阵营。
3. **每回合三选一**：
   - **翻牌**：翻开任意一张暗牌（翻开后属于它自己那一方）；
   - **走牌**：自己的明牌走一格到空格（默认只能上下左右，不能跳牌）；
   - **吃牌**：吃掉相邻的对方明牌，级别大的吃级别小的，**同级不能互吃**（龙王吃不了虎王）。
4. **王与最小牌的单向克制**（默认，照斗兽棋「象吃不了鼠」的规矩）：
   - **龙王吃不了小王虎**、**虎王吃不了变形龙**——最强的牌拿对方最小的那张没办法；
   - 反过来**小王虎能吃龙王**、**变形龙能吃虎王**（反杀照旧）；
   - 其他龙／虎（神龙、金龙、东北虎……）照常能吃对方最小的牌；
   - 设置里可改成「能（纯按级别）」，即龙王也能吃小王虎。
5. **其他特殊牌**：
   - **变形龙(8) 能吃虎王(9)**；
   - **小王虎(16) 能吃龙王(1)**（设置里可改成「通吃所有龙牌」）。
6. **胜负**：吃掉对方全部 8 张牌者胜；轮到某方既无牌可翻、又无子可动，该方判负。
7. **附加规则（本作加的，防止死局）**：两种情况判**和棋**——① 牌全部翻开后，双方剩下的牌彼此都吃不动（比如只剩两只同级牌）；② 连续多手双方都没吃到牌（默认 60 手，可改成 100 手或「不限」）。不加这两条，残局会一直磨下去，永远分不出结果。

**操作**：点暗牌＝翻牌；点自己的明牌＝选中（**绿点**可走、**红圈**可吃）；点目标格＝执行；再点一次已选中的牌＝取消选择。

**设置项**（点「设置」展开，改完点「新开一局」生效）：

| 设置 | 默认 | 说明 |
|---|---|---|
| 棋盘 | 4 × 4 | 可选 5×5、6×6，格子多、走位更自由 |
| 允许斜走一格 | 关 | 老玩法有地区差异，开着更像象棋走法 |
| 小王虎通吃所有龙牌 | 关 | 关＝只吃龙王（怀旧文口径）；开＝百科条目口径 |
| 王能吃对方最小牌吗 | **不能**（斗兽棋式） | 默认龙王吃不了小王虎、虎王吃不了变形龙，但反杀有效；改成「能」即纯按级别吃 |
| 无吃子判和 | 连续 60 手 | 连续这么多手没人吃子就判和，防止无限磨；可选 100 手或「不限」 |
| 玩家昵称 | 玩家1／玩家2 | 同屏玩时方便认清轮到谁 |

界面还有「悔棋」（可连续回退，**联机时禁用**）和「对局记录」。

## 二、联机对战（输房间号就能玩，不用服务器）

「对战方式」里选 **创建房间** 或 **加入房间**：

1. **房主**：选「创建房间（我当房主）」→ 页面显示一个 **6 位房间号**（例如 `9AW8BX`），把它发给对手；
2. **对手**：选「加入房间」，输入房间号、点「加入」→ 立刻进入同一局；
3. **观众**：第三个人及以后进同一个房间号即自动成为**观众**，只能看不能动，房主的房间栏会显示观众人数。

| 机制 | 做法 |
|---|---|
| 谁说了算 | **房主权威**：每一步都由房主用规则引擎校验后广播完整局面，双方看到的永远一致 |
| 规则谁定 | 房主。对手的棋盘尺寸/斜走/判和等设置会锁住（跟随房主的快照） |
| 悔棋 | 联机时禁用；只有房主能「新开一局」，重开后对手与观众一起重置 |
| 掉线 | 自动重连（换备用中继），重连后房主补发当前局面；房间栏显示对手「在线/掉线」 |
| 丢包 | 走子未确认会自动重发（最多 4 次）；房主每 15 秒补发一次局面，保证最终一致 |

**中继**：免费公共 MQTT（`broker.emqx.io`，备选 HiveMQ / Mosquitto），用 WebSocket 直连，**不需要任何服务器或账号**；页面里那套 MQTT 协议是手写的，所以**依然是零依赖单文件**。

> ⚠️ **安全边界**：这是**公共频道、不加密**（当初权衡后选的方案）。传输内容只有棋局数据（翻哪张牌、走哪一步）和昵称，不含任何个人信息；但**知道房间号的人理论上可以订阅看到这局棋，也可能发消息冒充对手走一步**（恶作剧级，改不了代码、拿不到隐私）。
> 想挡掉偷看：可以再加一层 WebCrypto（房间号派生密钥 + AES-GCM + 签名），随时能加。
> 另外：QQ/微信内置浏览器可能限制长连接，联机建议点右上角「**在浏览器中打开**」。

## 三、怎么发到 QQ 群

### 方案 A：GitHub Pages（推荐，一次部署长期可用）

**网页点点点版：**

1. 登录 GitHub → 右上角 `+` → **New repository**；
2. 仓库名填 `longhudou`，可见性选 **Public**，点 **Create repository**；
3. 进入仓库 → **Add file → Upload files** → 把本目录的 `index.html` 拖进去 → **Commit changes**；
4. 仓库 **Settings → 左侧 Pages** → Source 选 **Deploy from a branch**，Branch 选 **main**、目录选 **/(root)** → **Save**；
5. 等 1～2 分钟刷新，Pages 页面顶部会显示：

   ```
   Your site is live at https://<你的用户名>.github.io/longhudou/
   ```

6. 把这个链接发到 QQ 群即可。

**命令行版：**

```powershell
cd D:\workspace\longhudou
git init
git add index.html README.md
git commit -m "龙虎斗 兽棋版 网页游戏"
git branch -M main
git remote add origin https://github.com/<你的用户名>/longhudou.git
git push -u origin main
# 然后仍要到 Settings → Pages 里把分支设成 main / (root)
```

> 小提示：如果不想在群里暴露 `index.html` 这个文件名也完全没关系，仓库根目录的 `index.html` 会被自动当作首页；`README.md` 和 `tools/` 不影响访问。

### 本机已有的便携版 Git（这台机器上就这么推）

这台机器没装系统级 Git，但 `D:\workspace\tools\git\` 里有一份便携版 MinGit（没进 PATH，用全路径调用即可）。
`D:\workspace\longhudou` 已经初始化好并完成了首次提交（分支 `main`），只差推到 GitHub：

```powershell
$git = 'D:\workspace\tools\git\cmd\git.exe'
Set-Location 'D:\workspace\longhudou'
& $git remote add origin https://github.com/<你的用户名>/longhudou.git
& $git push -u origin main
# 然后再去仓库 Settings → Pages 把分支设成 main / (root)
```

推送要登录 GitHub：**GitHub 已不接受账号密码**，密码位置要填 **Personal Access Token**（https://github.com/settings/tokens 新建 classic token，勾 `repo` 权限）。
便携版里自带 Git Credential Manager，也可以先跑一次 `& $git config --system credential.helper manager`，推送时会弹浏览器让你登录 GitHub。

以后改动推送：

```powershell
$git = 'D:\workspace\tools\git\cmd\git.exe'
Set-Location 'D:\workspace\longhudou'
& $git add -A ; & $git commit -m "更新说明" ; & $git push
```

> 便携版的系统级配置已经顺手设好：`safe.directory`（否则会报 "dubious ownership"）、`core.autocrlf=false`（中文与换行不会被改坏）、提交身份 `longhudou <longhudou@example.com>`（占位）。
> 想换成自己的身份：`& $git config --system user.name "你的名字"` 与 `& $git config --system user.email "你的邮箱"`，然后 `& $git commit --amend --reset-author`。

### 方案 B：直接把文件发群文件

不想折腾托管时最省事：把 `index.html`（可改名成 `龙虎斗.html`）发到群文件。

- **安卓 / Windows**：下载后用浏览器打开即可；
- **iPhone**：在「文件」App 里找到它 → 分享 → 用 Safari 打开；
- 也可以先在自己手机上打开，然后「添加到主屏幕」，全屏当 App 玩。

### 关于国内访问 github.io

GitHub Pages 在国内部分网络下会慢或打不开（DNS 干扰），可以：

- 让群友**换个网络/多刷几次**，通常能开；
- 或者用同一个仓库在 **Cloudflare Pages / Netlify / Vercel** 建个镜像（Cloudflare Pages 国内多数地区能直连），把那个域名发群；
- 或者干脆用**方案 B**（群文件）。

群里发链接时最好补一句：**若页面排版异常，点右上角「在浏览器中打开」**（QQ/微信内置浏览器基本都能跑，个别老版本可能有问题）。

## 四、牌面插画

翻开的牌默认显示**画片插画**：图被自动切成 16 张，缩到 180px 宽后转成 base64 **内嵌在 index.html 里**，所以仍然是单文件、离线可玩（当前这副是动漫风格的一套，index.html 约 460KB）。

- **按牌号对号入座**：不同画片的排列顺序不一样（现在这副按阅读顺序是 `14,9,16,4 / 2,12,6,15 / 8,11,5,1 / 3,13,7,10`），切图脚本用 `LONGHUDOU_LAYOUT` 指定映射，输出文件名始终是**牌号**（`card01.jpg` = 1 号龙王）。
- **保持原画比例**：切图时把 16 张统一到同一宽高比（当前约 0.77），只往背景补、不裁画面；页面按这个比例显示，棋盘宽度自动适配屏幕。
- **牌名差异**：这副画片第 3 张印「**金蛟**」、第 15 张印「**良虎**」，而百科条目写作「金龙」「白虎」——本作文字仍按条目。想统一成画片的写法，改 `tools/index.template.html` 里的 `CARDS` 名字即可（连带改测试里的两处断言）。
- 牌背文字是简体的「**龙虎**」；关掉插画后文字牌面的水印也是简体「龙 / 虎」。
- 不想看图：设置里取消「牌面用画片插画」，立刻切回文字牌面（纯外观开关，不影响规则、不用重开）。

### 换一套画片 / 换回最早的洋画片

```powershell
$env:LONGHUDOU_ROOT    = 'D:\workspace\longhudou'
$env:LONGHUDOU_SHEET   = 'D:\workspace\longhudou\tools\sheet-new.png'  # 你的画片
$env:LONGHUDOU_LAYOUT  = '14,9,16,4,2,12,6,15,8,11,5,1,3,13,7,10'     # 按阅读顺序写每格是几号牌
$env:LONGHUDOU_MONTAGE = '1'                                          # 可选：输出核对图（按牌号排列）
Invoke-Expression (Get-Content -Raw -Encoding UTF8 .\tools\slice-sheet.ps1)
Invoke-Expression (Get-Content -Raw -Encoding UTF8 .\tools\embed-art.ps1)
```

> 最早的「洋画片」那套卡图保留在 `tools/tiles-classic/`（已 gitignore）。要换回去：把那 16 张拷回 `tools/tiles/`，再跑一次 `embed-art.ps1`。

> 注意：**根目录的 `index.html` 是生成物**（由 `tools/index.template.html` + `tools/tiles/*.jpg` 生成）。
> 以后要改界面、规则或联机逻辑，请改 `tools/index.template.html`，再跑一次 `embed-art.ps1` 重新生成。

```

├─ index.html                 游戏本体（生成物：单文件、内嵌插画 + 联机协议，直接双击或托管即可）

   ├─ slice-sheet.ps1         把整张画片切成 16 张小卡图
   ├─ embed-art.ps1           把卡图转 base64 注入模板，生成 index.html
   ├─ tiles/card01..16.jpg    切好的卡图（中间产物，已 gitignore）
```

跑测试（需要 Node.js）：

```powershell
node tools\test-engine.cjs        # 规则引擎：吃子矩阵、翻牌定阵营、走子/吃子合法性、
                                  # 歼灭与无棋可走判负、两种和棋判定 + 300 局随机自对弈
node tools\test-net.cjs           # 联机：MQTT 报文编解码、快照校验、整局同步、观战、拒绝非法走子、
                                  # 回合校验、过期意图、丢包重发、broker 回显（全部离线）
```

## 六、规则出处与差异说明

- 牌面、级别与「数字小者胜」的比大小玩法：整理自[百度百科「龙虎斗（纸质游戏牌）」](https://wapbaike.baidu.com/item/%E9%BE%99%E8%99%8E%E6%96%97/4302675)条目；
- 兽棋（翻牌走子）玩法：整理自 2018 年网易／新浪的怀旧文章[《盘点十几年前的7款纸牌游戏》](https://k.sina.com.cn/article_6470977609_181b34849001007yrv.html)；
- 这些都属于**民间流传玩法**，不是当年的印刷说明书，各地在「能否斜走」「小王虎是只吃龙王还是通吃龙牌」「王能不能吃对方最小牌」「棋盘多大」上说法不一，所以本作把有争议的部分做成了设置项，你们群里按自己那套约定调就行。
- 网上流传的「龍虎鬥遊戲牌」图片多为后人重绘/AI 生成的仿旧图（例如第 15 张常被写成「良虎」，条目里写作「白虎」），考据时请注意分辨。
